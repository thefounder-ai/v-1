# SkillOrbit / Plan Dot Tech

## Project overview

SkillOrbit is an AI Career Learning Navigator for the SmartReco Build Challenge 2026. It observes learner behavior, retrieves real catalog resources using semantic search, and generates explainable, personalized next-step recommendations.

The source-of-truth product and implementation plan is `PLAN_DOT_TECH.md`. Read it before implementing or changing the architecture.

## User preferences

- Build in small phases.
- Review and verify after every phase.
- Keep the interface natural, calm, and professional.
- Avoid excessive animation and visual effects.
- Prioritize a real working demo over broad but shallow features.
- Use original or properly attributed/open resources; do not copy third-party course content.
- Keep the final implementation aligned with the challenge requirement that all AI calls use Mesh API.
